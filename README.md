# O Kart

React + Vite storefront project.

## Publish to GitHub Pages

1. Create a GitHub repository for this project.
2. Add the remote in this folder:
   ```bash
git remote add origin https://github.com/<username>/<repo>.git
```
3. Push the code:
   ```bash
git push -u origin main
```
4. GitHub Actions will build and deploy to the `gh-pages` branch automatically.
5. The public URL will be one of:
   - `https://<username>.github.io/<repo>/`
   - `https://<custom-domain>/` if you configure a custom domain.
